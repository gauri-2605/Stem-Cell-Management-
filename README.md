# Stem-Cell-Management-
**Stem Cell Management System** is a web-based application designed to manage and organize stem cell donor, patient, and stem cell sample information efficiently. The system helps maintain records, track available stem cells, and simplify the management of stem cell-related data through a user-friendly interface.

### Key Features

* Donor and patient information management
* Stem cell sample record management
* Search and update records
* Secure data storage
* Easy-to-use interface
* Efficient database management
* Organized retrieval of stem cell information

**Technologies Used:** HTML, CSS, JavaScript, PHP, MySQL
